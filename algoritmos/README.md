Exercícios da disciplina de Algoritmos (Prof. Manoel), feitos em Python para praticar lógica de programação. Cada arquivo é um programa independente, numerado na ordem em que foi resolvido.

## Como rodar

Abra o terminal na pasta do projeto e execute o arquivo do exercício que quiser:

```bash
python 1helloworld.py
```

Troque `1helloworld.py` pelo nome de qualquer outro arquivo (por exemplo, `33imc.py`). Em alguns sistemas o comando é `python3`. Não há dependências externas.
