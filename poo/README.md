Estudos de **Programação Orientada a Objetos** em duas linguagens: o mesmo paradigma (classes, objetos, herança e polimorfismo) aplicado em JavaScript e em Python.

## Projetos

| Pasta | Linguagem | O que é |
|---|---|---|
| [`javascript/`](javascript/) | JavaScript, HTML, CSS | Cadastro de alunos no navegador (Aula 6 de POO) |
| [`python/`](python/) | Python | Trabalho de POO em Python |

## Conceitos de POO estudados

| Conceito | Exemplo no projeto |
|---|---|
| **Classe** | `Pessoa` e `Aluno` |
| **Herança** | `Aluno extends Pessoa` |
| **Construtor / `super`** | `Aluno` reaproveita o construtor de `Pessoa` |
| **Polimorfismo** | `apresentar()` é sobrescrito em `Aluno` e chama `super.apresentar()` |
